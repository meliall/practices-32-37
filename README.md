# Практические работы №32–37

Репозиторий: https://github.com/meliall/practices-32-37

Все работы собраны в одной папке. №35 выполнена по варианту **21**, №37 — по варианту **27**. Работы №38–39 исключены по просьбе студента.

## Состав

| Папка | Работа и основная логика |
| --- | --- |
| `pr32-vue-router` | Каталог курсов: Vue Router, вложенные страницы курса, фильтр в query, вход и защищённая страница, 404. |
| `pr33-forms-validation` | Регистрация: реактивная форма, проверка полей, отправка через Axios, состояния загрузки, успеха и ошибки. |
| `pr34-pinia-cart` | Каталог и корзина: Pinia, getters и actions, localStorage, лимит 10 товаров, избранное, отмена и экспорт JSON. |
| `pr35-auth` | Роли user/admin, токен, guard, запрос к API; вариант 21 — демонстрационная регистрация с ролью user. |
| `pr36-express` | Установка Express и сервер с GET, POST, PUT, DELETE и параметром `:id`. |
| `pr37-express-basics` | Маршруты, middleware, JSON, статика, ошибки; вариант 27 — `POST /trim`. |

В исходниках написаны комментарии на русском: они объясняют назначение проверок и порядок изменения данных. В каждой папке есть свой README. Эта копия подготовлена для одного общего репозитория GitHub. Новых загрузок на GitHub при подготовке этого комплекта не выполнялось.

## Как запустить

Понадобятся Node.js и npm. Проверено на Node.js 24.22.1 и npm 11.19.1. Откройте терминал в этой папке и установите зависимости всех проектов:

```sh
npm run setup
```

Затем запускайте нужную работу отдельной командой. Терминал с запущенным сервером оставляйте открытым; остановка — Ctrl+C.

| Команда из общей папки | Адрес |
| --- | --- |
| `npm run dev:32` | http://localhost:5232 |
| `npm run dev:33` | http://localhost:5233 |
| `npm run dev:34` | http://localhost:5234 |
| `npm run dev:35` | http://localhost:5235 |
| `npm run start:36` | http://localhost:3000 |
| `npm run start:37` | http://localhost:3000 |

У №36 и №37 одинаковый стандартный порт, поэтому запускайте их по очереди. Для одновременной работы на macOS можно выполнить `PORT=3001 npm run start:37` и открыть http://localhost:3001.

В работе №32 используется учебный пароль `1234`. В №35 доступны пары `user / user123` и `admin / admin123`; новая демо-регистрация сразу открывает профиль с ролью user. Реальной серверной базы пользователей в этой работе нет. Запросы №33 и №35 к JSONPlaceholder требуют интернета.

Зависимости `node_modules` и результаты сборки `dist` не входят в архив. Команда установки восстановит зависимости по включённым `package-lock.json`.

## Отчёт и подтверждения

Word-отчёт «Отчет по практикам 32–37 по образцу.docx» оформлен по предоставленному примеру: титульный лист, содержание, рамки и штамп, цели, ход работ, результаты, ответы и выводы. В нём 63 страницы книжного формата. Весь написанный код 64 файлов показан по ходу практик, рядом с соответствующими заданиями. Данные студента и преподавателя сохранены из образца.

Папка `screenshots/vscode` содержит исходные снимки настоящего окна Visual Studio Code. В Word показана область редактора с номерами строк: лишние панели, пустые поля и повторяющиеся участки соседних кадров обрезаны. PNG не перерисованы. Длинные файлы приведены до последней строки, включая шаблоны Vue, стили, тесты и настройки.

В `screenshots/vscode-terminal` находятся реальные снимки встроенного терминала VS Code: версии среды, HTTP-запросы, ответы, журнал и запуск Newman. Остальные снимки показывают работающие приложения в браузере. Папка `verification` содержит фактические JSON-ответы, сведения о среде, журналы и списки коммитов. `vscode-screenshots.json` связывает каждый исходник со снимками и контрольной суммой, `vscode-report-crops.json` фиксирует границы обрезки в Word, `полный-код-указатель.md` указывает страницы отчёта.

Скриншоты охватывают весь написанный код проекта. Автоматически сформированные `package-lock.json` включены в комплект для установки зависимостей; файлы сторонних библиотек и `node_modules` в листинги не входят.

## Проверки

Из папки каждого проекта №33–37 запустите `npm test`. Всего успешно выполнены 50 тестов: 17 + 8 + 8 + 5 + 12. Для Vue-проектов №32–35 также выполнена сборка `npm run build` и проверка интерфейса в браузере.

В папке №37 команда `npm run test:postman` запускает временный сервер и коллекцию Postman через Newman: 9 запросов, 18 проверок, без ошибок. Коллекция лежит в `postman/practice37.postman_collection.json`; её можно импортировать в графический Postman и указать переменную `baseUrl`, например `http://localhost:3000`. Фактический результат автоматического запуска сохранён в `pr37-express-basics/verification/postman-results.json`.
