# Практическая работа №32

Мини-приложение «Каталог курсов» на Vue 3 и Vue Router 4.
Реализованы все восемь пунктов задания. Данные трёх курсов перенесены из примера в документе.

## Запуск

В терминале откройте папку проекта и выполните:

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite, обычно http://127.0.0.1:5173.
Для входа используйте пароль **1234**.

Сборка:

```sh
npm run build
npm run preview
```

Папку `dist` создаёт команда сборки. Приложение запускается через HTTP-сервер,
а не двойным щелчком по `index.html`. При размещении на хостинге для
`createWebHistory` требуется перенаправление неизвестных серверу путей на `index.html`.

## Соответствие заданию

1. `src/router/index.js`: все маршруты из задания, дочерние маршруты вкладок,
   `meta.requiresAuth`, `meta.guestOnly` и глобальный `beforeEach`.
2. `src/data/courses.js`: отдельный массив из трёх курсов с описаниями, программами и отзывами.
3. `src/pages/CoursesListPage.vue`: чтение `route.query.category`, фильтры через `router.push`,
   карточки курсов, спиннер при монтировании на 1000 мс, сообщение об ошибке и повторная загрузка.
4. `src/pages/CoursePage.vue`: поиск по `route.params.id`, относительные `RouterLink`,
   вложенный `RouterView`, передача вычисляемого курса через `provide`, сообщение для неизвестного ID.
5. Три компонента `CourseDescriptionPage.vue`, `CourseProgramPage.vue`, `CourseReviewsPage.vue`
   получают курс через `inject`. Программа — нумерованный список; отзыв содержит автора, текст и рейтинг.
6. `LoginPage.vue`: пароль `1234` сохраняет `authToken` со значением `demo` в `localStorage`.
   После входа открывается запрошенный защищённый адрес или `/dashboard`.
   `DashboardPage.vue`: сообщение «Личный кабинет. Вы авторизованы.» и выход с удалением токена.
7. `NotFoundPage.vue`: «Страница не найдена» и ссылка-кнопка «На главную».
8. `src/App.vue`: только `<RouterView />` внутри шаблона. Общая навигация вынесена в `PageLayout.vue`.

## Адреса для проверки

| Адрес | Результат |
| --- | --- |
| `/` | Главная со ссылкой на каталог |
| `/courses` | Все три курса |
| `/courses?category=all` | Все три курса |
| `/courses?category=frontend` | Два курса Frontend |
| `/courses?category=backend` | Один курс Backend |
| `/courses/1` | Переход к описанию первого курса |
| `/courses/1/description` | Описание |
| `/courses/1/program` | Четыре темы программы |
| `/courses/1/reviews` | Автор, текст и оценка отзыва |
| `/courses/999` | Сообщение «Курс не найден» |
| `/dashboard` без входа | Переход на вход с сохранением целевого адреса |
| `/login` после входа | Переход в кабинет |
| `/no-such-page` | Страница 404 |

Неизвестная категория показывает сообщение об отсутствии курсов.
Если пароль неверный или `localStorage` недоступен, форма показывает ошибку.
Защита учебная, соответствует заданию и использует только `localStorage`.

## Уточнение по редиректу

В формулировке задания упомянут `from.fullPath`. В guard сохранены оба значения:
`from.fullPath` в query-параметре `from` и `to.fullPath` в `redirect`.
`from` означает страницу, с которой выполняется переход, а `to` — запрошенный адрес.
Для возврата после входа используется `redirect`: это позволяет сохранить защищённый
адрес вместе с его query и hash. При обычном открытии `/login` после входа открывается `/dashboard`.

Объяснение аргументов guard: https://router.vuejs.org/guide/advanced/navigation-guards.html.
Вложенные маршруты: https://router.vuejs.org/guide/essentials/nested-routes.html.
