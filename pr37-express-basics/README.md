# Практическая работа 37 — базовые принципы Express

**Вариант 27:** POST `/trim` принимает `{ "text": " abc " }` и возвращает JSON-строку `"abc"`.

Установка: `npm install`. Запуск: `npm start` (или `node index.js`).
По умолчанию адрес `http://localhost:3000`. Для другого порта: `PORT=3001 npm start`.

Выполнены все шесть заданий:
1. npm-проект, пакет Express и базовый GET `/`.
2. GET `/hello/:name`, GET `/math/add?a=1&b=2`, проверка неверных параметров.
3. Глобальное логирование ISO-времени, метода и URL; запрос передаётся дальше через `next()`.
4. `express.json()` и POST `/users`, случайный `id`, статус 201 и проверка имени.
5. Статический `public/info.html`, JSON-ошибка 404 и middleware ошибок с четырьмя аргументами.
6. Вариант 27: удаление крайних пробелов; пробелы внутри строки сохраняются.

Проверки: `npm test` (12 тестов), `npm run test:postman` (9 запросов, 18 проверок Postman).
Коллекция `postman/practice37.postman_collection.json` импортируется в Postman.
В коллекции задайте переменную `baseUrl`, обычно `http://127.0.0.1:3000`.
Автоматический запуск выполнен Newman — командным инструментом Postman для коллекций.
Результаты сохраняются в `verification/postman-results.json`.

Ответы на вопросы задания 1:
- `require('express')` загружает экспорт установленного пакета Express в переменную.
- `app.listen` запускает HTTP-сервер и начинает принимать подключения на указанном порту.
Без него маршруты будут объявлены, но браузер не сможет подключиться к этому приложению.
