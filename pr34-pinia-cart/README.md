# Практическая работа 34 — управление состоянием Pinia

Установка: `npm install`. Запуск: `npm run dev`. Проверка: `npm test`, сборка: `npm run build`.

По заданию настроены `/` и `/cart`, store корзины `cart`, второй store `favorites`.
Товары и цены взяты из примера: ноутбук 75000, смартфон 35000, наушники 5000, клавиатура 4000 рублей.

`state` хранит позиции, `getters` считают количество и стоимость, `actions` изменяют корзину.
Компоненты не меняют store напрямую. Корзина сохраняется в `localStorage` с ключом `cart_items`.
JSDoc описывает типы товаров и позиций, сохраняя структуру JavaScript из теории.

Продолжение задания выполнено полностью:
- Лимит 10 штук суммарно, включая изменение количества кнопкой «+».
- Счётчик избранного в шапке; состояние находится во втором store.
- «Отменить» откатывает последнее добавление, удаление, очистку или изменение количества.
- «Скачать корзину» экспортирует актуальное содержимое, количество и сумму в `cart.json`.

Отмена одноуровневая, как требует формулировка «последнего действия».
Снимок хранится в памяти, сами товары восстанавливаются после перезагрузки.
8 автоматических проверок охватывают сумму, лимит, отмену, сохранение и избранное.
