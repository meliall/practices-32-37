# Практическая работа №33

Форма регистрации на Vue 3 с Composition API, живой валидацией и отправкой через Axios.
Проект выполнен по заданию «Формы и валидация».

## Запуск

Установите Node.js с npm. Откройте терминал в папке проекта и выполните:

```sh
npm install
npm run dev
```

Откройте локальный адрес, который напечатает Vite, обычно http://127.0.0.1:5173.
Запускайте приложение через сервер Vite, а не двойным щелчком по `index.html`.

## Реализация задания

- Создан проект Vue 3 и установлен Axios.
- Форма находится в `src/pages/RegistrationPage.vue`.
- В `src/App.vue` импортирован компонент, в шаблоне стоит `<RegistrationPage />`.
- Как в примере, используются `reactive`, `ref`, `v-model`, состояния ошибок,
  загрузки и успешной отправки. `@submit.prevent` предотвращает перезагрузку страницы.
- Добавлены CSS-стили в `src/style.css`: обычные и ошибочные поля, кнопка,
  индикатор загрузки и адаптация к узкому экрану.
- Пароль проверяется по итоговому заданию: минимум 8 символов, строчная и
  прописная буквы, цифра и специальный символ. Поддерживаются русские и латинские буквы.
- Ошибки появляются при `@blur`, затем обновляются при `@input`.
  После попытки отправки ввод сразу перепроверяет все затронутые поля.
- Изменение пароля также перепроверяет подтверждение, если оно уже было проверено.
- Данные отправляются через `axios.post`, без `fetch`.
  В `.catch` различаются ответ сервера с ошибкой, отсутствие ответа, тайм-аут и прочая ошибка.
  В `.finally` снимается состояние загрузки.
- Пока идёт отправка, поля и кнопка блокируются. Повторный клик не создаёт второй запрос.

## Как работает практика

1. Браузер открывает `index.html` и загружает `src/main.js`. Этот скрипт создаёт
   приложение Vue и размещает его в элементе с `id="app"`.
2. Корневой компонент `App.vue` выводит `RegistrationPage.vue`.
   Внутри страницы `script setup` хранит состояние и функции, а `template` описывает форму.
3. Ввод через `v-model` меняет свойства объекта `form`. Этот объект создан через
   `reactive`, поэтому Vue отслеживает изменения и обновляет страницу автоматически.
4. При уходе из поля срабатывает `@blur`: функция `handleBlur` отмечает поле
   в `touched` и вызывает `validateField`. Если значение неверное, в `errors`
   записывается сообщение. `v-if` показывает текст, а `:class` подсвечивает поле.
5. При дальнейшем вводе срабатывает `@input`. Функция `handleInput` перепроверяет
   редактируемое поле, если его уже проверяли. Исправленная ошибка исчезает сразу.
   При изменении исходного пароля повторно проверяется и уже затронутое подтверждение.
6. Нажатие «Зарегистрироваться» или Enter вызывает `handleSubmit`.
   Модификатор `.prevent` отменяет стандартную отправку формы с перезагрузкой страницы.
   Функция `validate` проверяет все поля, включая пропущенные. Если есть хотя бы одна
   ошибка, выполнение заканчивается до HTTP-запроса.
7. Если ошибок нет, `isLoading` становится `true`, форма блокируется, кнопка показывает
   «Отправка…». Из `form` собирается объект `payload`: у имени и email убираются пробелы
   по краям, пароли остаются без изменений. Axios отправляет объект методом POST.
8. `.then` показывает успех после удачного ответа. `.catch` выбирает сообщение по
   причине ошибки: ответ сервера, тайм-аут, отсутствие ответа или другая проблема.
   `.finally` при любом результате сбрасывает `isLoading`, разблокируя форму.

`ref` используется для отдельных значений: `isLoading`, `successMessage`, `generalError`.
В JavaScript к ним обращаемся через `.value`, например `isLoading.value = true`.
В шаблоне Vue раскрывает их автоматически: достаточно написать `:disabled="isLoading"`.

`reactive` используется для объектов: `form` содержит данные, `errors` — сообщения
об ошибках полей, `touched` — признаки уже проверенных полей. К их свойствам
обращаемся напрямую: `form.name`, `errors.email`, `touched.password`.

Пример работы: пользователь вводит `anna@` и уходит из поля Email.
`handleBlur('email')` запускает проверку, и появляется «Введите корректный email».
Пользователь исправляет адрес на `anna@example.com`; `handleInput('email')`
сразу проверяет новое значение и убирает ошибку, не дожидаясь отправки.

## Правила валидации

| Поле | Проверка |
| --- | --- |
| Имя | Не менее 2 символов после удаления пробелов по краям |
| Email | Формат `имя@домен.зона`; пробелы по краям удаляются |
| Пароль | От 8 символов, строчная и прописная буквы, цифра, спецсимвол |
| Подтверждение | Обязательное поле, точное совпадение с паролем |

Пробел не считается специальным символом. Пароль не обрезается и не изменяется перед отправкой.

Для проверки можно использовать вымышленные данные:

- Имя: `Анна`
- Email: `anna@example.com`
- Пароль и подтверждение: `Vue2026!`

## Учебная отправка

Как в примере практики, используется `POST https://jsonplaceholder.typicode.com/users`.
Отправляются `name`, `email`, `password` и `confirmPassword`. Тайм-аут — 10 секунд.
После успешного ответа отображается «Регистрация успешно отправлена (демо).»

Это тестовый API: он имитирует создание записи, а не создаёт реальный аккаунт.
Для настоящего проекта дополнительно нужна валидация на бэкенде.
Описание сервиса: https://jsonplaceholder.typicode.com/.

## Проверка

```sh
npm test
npm run build
npm run preview
```

Успешно пройдены 17 автоматических тестов и сборка Vite.
Тесты выполняют настоящий `script setup` компонента через компилятор Vue.
HTTP-адаптер Axios в тестах подменяется, чтобы воспроизводимо проверить
успех, ошибку сервера, сетевую ошибку, тайм-аут и повторную попытку без внешних запросов.
Также проверяются все требования к паролю, имя и email, подтверждение,
живая валидация, состав POST-запроса и защита от повторной отправки.

В браузере отдельно проверены появление ошибок по потере фокуса, исправление
ошибок при вводе, несовпадение паролей, блокировка формы во время запроса
и успешная реальная отправка вымышленных данных на JSONPlaceholder.
